  <action>Create `src/shared/format.ts` with two exports. (1) `fmt(n: number): string` — canonical decimal formatter implementing exactly the D-35 semantics: normalize negative zero to zero (Object.is check), format with Number.prototype.toFixed(4) (the tie-breaking and rounding are fully specified by ECMA-262, hence identical across engines — this is WHY D-35 chose it), strip trailing zeros then a dangling dot, and re-map any residual "-0" to "0". Add a module guard that throws on non-finite input and on |x| >= 1e21 (outside project bounds — coords 0..1, viewBox <= 2048, lottie units <= a few thousand; toFixed cannot emit exponential notation below that bound, D-35). The SAME function is the formatter for SVG numeric attributes (D-35: "même formateur pour les attributs numériques du SVG") — do not fork a second formatter. (2) `writeDeterministicJson(path: string, value: unknown): void` plus `serializeDeterministicJson(value: unknown): string` — a hand-written recursive walker (objects in key insertion order, arrays in order) that emits COMPACT JSON (no spaces) routing every finite float through fmt(), strings through the standard JSON string escaping, and appends exactly one trailing "\n" byte when writing files (D-24: compact + final newline; the goldens are exactly the delivered bytes). Write files with the "\n" escape literal — never os.EOL (Pitfall 9; .gitattributes eol=lf already committed in Phase 1, do not touch it). Do not use the native JSON serializer for the float-bearing output path — it emits shortest-roundtrip floats (0.30000000000000004) which violates D-23. Pure module, zero dependencies, docblock citing D-23/D-24/D-35 and its position as the numeric-format authority for all Phase 3 output. Then `src/shared/format.spec.ts`: exact-case matrix using ONLY exact-binary values so assertions are engine-independent — fmt(0)==="0", fmt(2.5)==="2.5", fmt(0.1+0.2)==="0.3", fmt(1/3)==="0.3333", fmt(-1/3)==="-0.3333", fmt(-0)==="0", fmt(0.00001)==="0", fmt(100)==="100", fmt(3.14159265)==="3.1416", fmt(0.5519150244935105707435627)==="0.5519" (the lottie circle kappa), fmt(1234.5678)==="1234.5678"; guard cases: fmt(NaN) throws, fmt(Infinity) throws, fmt(1e21) throws; serializer cases: nested object/array fixture serializes to an exact expected string literal (insertion order preserved, floats formatted, compact), and a file write ends with exactly one "\n" byte (read back as Buffer and assert last byte is 0x0a).</action>
