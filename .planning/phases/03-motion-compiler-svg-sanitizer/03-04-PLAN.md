## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RenderSpec (future agents/Translator) -> compile() | Structured input crossing zod; path data generated, never received |
| Raw SVG string -> sanitizeSvg() | The security surface — SVG is consumed by third parties (packs sold); XSS via SVG is the threat |
| CompileResult -> caller | Only gate-passing bytes leave the compiler (re-validation before return) |
